# MPL 주식 리그

친구들끼리 일주일 동안 가상 주식으로 총자산 1등을 겨루는 모바일 웹 게임.

## 게임 규칙

- **시즌:** 월요일 0시에 시작해서 일요일 22시에 끝나요. 시드 1,000만원을 받고 시작해요.
- **라운드:** 하루 3번(12시 점심장, 18시 퇴근장, 22시 야간장), 일주일에 21번. 뉴스, 업종 뉴스, 큰손 이벤트가 이때 한 번에 반영돼요.
- **실시간 가격:** 라운드 사이에도 가격이 2초마다 움직여요. 모든 기기가 시각을 기준으로 같은 가격을 계산해요.
- **종목:** 반도체·빅테크 등 실제 기업 이름 30개. 가격과 뉴스는 게임용 가상 데이터예요.
- **MPL 종합지수:** 30종목 평균. 월요일 개장을 1,000으로 둬요.
- **지원금:** 12시간마다 200만원이 자동으로 들어와요(0시, 12시).
- **게임:** 홀짝(1.95배), 룰렛(0~4배). 한 판 최대 200만원.
- **거래:** 매수, 매도, 공매도, 상환. 수수료 0.3%.
- **친구 정보:** 친구 지갑은 대표 종목 하나만 보여요. 하루 한 번 엿보기로 한 명의 지갑 전체를 볼 수 있어요.
- **종목 채팅:** 종목마다 채팅방과 "다음 라운드 오를까?" 투표가 있어요.

## 파일

- `gaemi-king.html` — 게임 전체(HTML, CSS, JS 한 파일).
  Claude Artifact로 배포하는 형식이라 `<!doctype>`, `<head>`가 없어요(게시할 때 자동으로 붙어요).
- `.claude/launch.json` — 로컬 미리보기 서버 설정.

## 데이터 저장

친구들 순위, 지갑, 소식, 채팅은 Claude Artifact의 공유 데이터베이스(`db` 기능)에 저장돼요.

- `players/<id>` — 각자의 지갑. 본인만 쓸 수 있어요.
- `feed` — 매매, 엿보기, 게임 소식.
- `talk` — 종목 채팅.

Artifact 바깥에서 열면 연습 모드로 동작해요. 연습봇 셋과 겨루고, 데이터는 브라우저에만 저장돼요.

## 로컬에서 보기

```bash
python3 -m http.server 5178
```

`gaemi-king.html`에는 문자 인코딩 선언이 없어요. 브라우저에서 한글이 깨지면 `<meta charset="utf-8">`이 들어간 래퍼 페이지로 열어야 해요.
