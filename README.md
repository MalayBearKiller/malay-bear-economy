# 썬빗 SUNBIT

말레이곰 × 업비트. 친구들끼리 총자산으로 겨루는 모바일 웹 게임. 돈은 **원화 하나**예요.

## 게임 규칙

- 처음 **50억원**(2026-11-12부터. 그 전 참가자는 앱을 열 때 한 번 +40억). 총자산 = 현금 + 코인(현물·선물) + 주식 + 구채. 순위는 총자산 순서.
- **코인**: 업비트 원화마켓 실제 시세(웹소켓). 현물 수수료 0.05%, 최소 주문 5,000원.
  - **선물 롱·숏**: 해외 선물거래소 방식. BTC·ETH 최대 100배, 알트 50배, 밈 25배. 수수료 0.05%, 펀딩비 8시간 0.01%, 유지증거금 0.5%. 약 1÷배수 반대로 가면 청산(증거금 전부 잃음). 앱이 꺼져 있던 동안은 업비트 분봉 최저·최고가로 확인.
- **주식**(미국 99종목, 11개 분류) · **현물**(금·은·백금·구리·원유·천연가스): CNBC 공개 시세(키 없음, 5초마다). 원화를 실시간 원/달러 환율로 자동 환전. 소수점 거래, 수수료 0.1%. 롱·숏: 주식 2·3배, 현물 2·5·10배.
- **거래소 탭**: 주식 · 코인 · 현물 · 채권(구채). 오른쪽 아래 💼 내 보유 버튼.
- **구채**: 서울 25개 구마다 100장. 가장 많이 가진 사람이 구청장. 1장 기본값 강남 1억 ~ 도봉 500만원, 팔린 비율만큼 최대 2.5배 + 시세 출렁임. 매시간 이자(0.03~0.08%), 환매 수수료 1%.
- **상점**: 홀짝·룰렛·레벨업·닉네임·배경도 같은 현금으로.
- **공격**(친구 프로필에서): 💰 수익 약탈(수익 중인 현물, 비용=수익의 25%, 성공 20%, 성공 시 수익 전부) · 🎯 마진 사냥(롱·숏, 비용=증거금 15%, 성공 20%+배수×0.2 최대 40%, 성공 시 증거금 50%, 청산가 닿으면 참수=전부). 실패 시 비용 절반은 상대 위자료. 쿨타임 10분/같은 종목 30분, 털린 종목 3시간 보호막, 10분 반값 복수. 당한 사람 앱이 기록(`sb_feed`의 `target`)을 보고 스스로 반영.
- **접속 중 표시**: 2분마다 `seen` 시각을 남겨요(화면 볼 때만).
- **지원금**: 2시간마다(짝수 시 정각) 420만원, 하루 약 5,000만원. 앱을 꺼 둬도 최대 7일치까지 쌓여요. 수익률 기준 금액에도 더해져요.
- **파산**: 총자산 100만원 밑이면 1,000만원 지원.

## 친구들과 같이 하기 (Firebase 설정)

로그인은 Google 계정, 데이터는 Firebase Firestore를 써요. 무료 요금제(Spark)로 충분해요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요).
2. **Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정.
3. **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드.
4. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기.
6. 배포한 주소(예: `malaybearkiller.github.io`)를 **Authentication → 설정 → 승인된 도메인**에 추가. `localhost`는 기본으로 들어 있어요.
7. 친구들에게 주소를 보내면 각자 Google로 로그인해서 참가해요.

`firebase-config.js`의 값은 비밀번호가 아니라 브라우저에 공개되는 식별자예요. 실제 보호는 보안 규칙이 해요.

## 데이터 구조

| 컬렉션 | 문서 | 누가 쓰나 |
|---|---|---|
| `sb_players/{uid}` | 지갑: 이름, 현금(cash), 코인(kHold·kFut), 주식(uHold), 구채(bonds), 레벨 | 본인만 |
| `sb_feed/{id}` | 매매·구채·환전 소식 | 본인 이름으로 추가만 |
| `sb_talk/{id}` | 종목 채팅·건의 | 본인 이름으로 추가, 본인 것만 삭제 |

예전 곰스피 컬렉션(`players`, `estates`, `feed`, `talk`)은 지우지 않고 그대로 둬요.

- 구채 시세는 저장하지 않아요. 시각으로 모든 기기가 똑같이 계산해요. 코인은 업비트, 주식·환율은 CNBC에서 받아요.
- 주가 바뀌어도 지갑·포지션·건물·채팅은 그대로 이어져요. 데이터는 초기화하지 않아요.
- 소식과 채팅은 쌓이기만 해요. 친구끼리 쓰는 정도면 몇 년을 써도 무료 한도에 한참 못 미쳐요.
