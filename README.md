# MPL 주식 리그

친구들끼리 일주일 동안 가상 주식으로 총자산 1등을 겨루는 모바일 웹 게임.

## 게임 규칙

- **시즌:** 월요일 0시에 시작해서 일요일 22시에 끝나요. 시드 100억원을 받고 시작해요.
- **장 마감:** 하루 3번(12시 점심장, 18시 퇴근장, 22시 야간장). 뉴스, 업종 뉴스, 큰손 이벤트가 이때 한 번에 반영돼요.
- **실시간 가격:** 장 사이에도 가격이 2초마다 무작위로 움직여요. 모든 기기가 시각을 기준으로 같은 가격을 계산해요.
- **종목:** 반도체·빅테크 등 실제 기업 이름 30개. 가격과 뉴스는 게임용 가상 데이터예요.
- **MPL 종합지수:** 30종목 평균. 월요일 개장을 1,000으로 둬요.
- **지원금:** 12시간마다 20억원이 자동으로 들어와요(0시, 12시).
- **게임:** 홀짝(1.95배), 룰렛(0~4배). 한 판 최대 20억원.
- **거래:** 매수, 매도, 공매도, 상환. 수수료 0.3%.
- **친구 정보:** 친구 지갑은 대표 종목 하나만 보여요. 하루 한 번 엿보기로 한 명의 지갑 전체를 볼 수 있어요.
- **부동산:** 서울 명소·대학·아파트·꼬마빌딩 52곳(꼬마빌딩 수십억 ~ 롯데월드타워 4조). 건물마다 최저가가 있고 그 위에서 주식처럼 움직여요. 12시간마다 가치의 0.5%가 임대료로 들어와요. 지도는 25개 구로 나뉘고, 구를 누르면 확대돼서 건물과 주인 이름이 보여요. 남의 건물은 가치의 50%로 파괴, 파괴된 건물은 멈춘 가치의 2배로 강제 매입(바로 복구). 주인은 50%로 복구할 수 있어요.
- **종목 채팅:** 종목마다 채팅방과 "오를까?" 투표가 있어요.

## 파일

| 파일 | 내용 |
|---|---|
| `gaemi-king.html` | 게임 전체 (HTML, CSS, JS 한 파일) |
| `index.html` | `gaemi-king.html`로 넘겨주는 시작 페이지 |
| `firebase-config.js` | Firebase 연결 설정. `null`이면 연습 모드만 동작 |
| `firestore.rules` | Firestore 보안 규칙 (콘솔에 붙여넣는 용도) |

## 친구들과 같이 하기 (Firebase 설정)

로그인은 Google 계정, 데이터는 Firebase Firestore를 써요. 무료 요금제(Spark)로 충분해요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요).
2. **Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정.
3. **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드.
4. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기.
6. 배포한 주소(예: `malaybearkiller.github.io`)를 **Authentication → 설정 → 승인된 도메인**에 추가. `localhost`는 기본으로 들어 있어요.
7. 친구들에게 주소를 보내면 각자 Google로 로그인해서 참가해요.

`firebase-config.js`의 값은 비밀번호가 아니라 브라우저에 공개되는 식별자예요. 실제 보호는 보안 규칙이 해요.

## 데이터 구조

| 컬렉션 | 문서 | 누가 쓰나 |
|---|---|---|
| `players/{uid}` | 지갑: 이름, 현금, 보유·공매도, 지원금 횟수, 투표, 엿보기 | 본인만 |
| `feed/{id}` | 매매·엿보기·게임 소식 | 본인 이름으로 추가만 |
| `talk/{id}` | 종목 채팅 메시지 | 본인 이름으로 추가, 본인 것만 삭제 |
| `estates/{건물}` | 건물 주인, 산 가격, 파괴 상태(멈춘 가치) | 로그인한 누구나 (매입·파괴·강제 매입) |

- 주가는 데이터베이스에 저장하지 않아요. 시즌 번호와 시각으로 모든 기기가 똑같이 계산해요.
- 매주 월요일 새 시즌이 되면 각자 다시 참가해요. 지난 시즌 지갑은 덮어써져요.
- 소식과 채팅은 쌓이기만 해요. 친구끼리 쓰는 정도면 몇 년을 써도 무료 한도에 한참 못 미쳐요.
