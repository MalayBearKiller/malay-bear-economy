# 서울 구채 (없어짐)

2026-11-12에 게임에서 뺀 서울 25개 구 구채 코드예요.

- 구마다 100장, 가장 많이 가진 사람이 구청장, 매시간 이자(강남 0.03% ~ 도봉 0.08%).
- 없앨 때 가진 사람에게 **현재가**(지금 다 팔면 받는 돈, 수수료 없음)로 원화 환불했어요.
  각자 다음 접속 때 자동으로 받아요(`js/gbond.js`의 `gRefund`).
- 환불받은 장수는 지갑의 `bondsRef`에 남아 있어요. 환불 기록은 `sb_feed`의 `k_refund`.
- 환불 계산에 필요한 가격 코드만 `js/oldbond.js`에 남겼어요. 시드(`bond1:`)는 바꾸면 안 돼요.
- 화면 스타일(`.bmap`, `.bhero`, `.brow` 등)은 `css/sunbit.css`에 그대로 있어요.

파일: `seoul-bonds.js` (원래 `krw.js`, `core.js`, `me.js`, `us.js`에 있던 부분)
